## What v4 corrects

1. **No repeated visual background or clip.** The finished timeline contains
   **35 moving source assets**: 32 one-time original 3D-style video tracks and
   three newly acquired public-domain NASA animations used once each.
2. **Strict deduplication is enforced before scene assembly.** The v4 build
   refuses duplicated source keys, resolved source filenames/paths, or
   SHA-256 content hashes. The final manifest records 35 unique values for all
   three checks.
3. The v3 repeat points are gone: no repeated framed jet/simulation visual and
   no repeated binary/wireframe visual are placed anywhere in the v4 timeline.
4. **A mandatory 2.8-second outro is generated by the build script.** It
   visibly says **FOLLOW UNIVERSE IMPACT** and **LIKE + SHARE TO A FRIEND**.
5. The single framed NASA simulation has a dedicated **SIMULATION** label,
   positioned safely *inside* the portal's top border and above its footage.
6. **Frame 1 is visible.** There is no fade-to-black lead-in; the active
   accretion visual appears on the first decoded video frame.
7. Every scene is rendered into a full **1080 × 1920** canvas; no pillarboxed
   composition is used.
8. The reviewed program audio is preserved. The locked AAC packet stream is
   stream-copied without remixing, gain, normalization, loudnorm, compression,
   limiting, or re-encoding. Its verified integrated loudness is **-16.0 LUFS**.

## Visual and rights scope

This is not a legacy v2 recut and it does not open the old `sources/` clips.
It also does not reuse a rendered v3 visual MP4.

- **32 original v4 animated tracks** are newly rendered from local geometry,
  particles, perspective/camera movement, dynamic glow, grids, and generated
  textures using `fresh_3d_visuals_v4.py`. The source families include
  accretion, lensing, binary orbit, lattice, jet, funnel, bounce, shell,
  spiral, cosmic web, pattern sphere, metric grid, wave, orbit sculpture,
  detector data, void, and outro.
- **Three fresh external animated sources** are NASA SVS 14132 public-domain
  animations from their documented Wikimedia Commons file pages: Supermassive
  Binary Black Hole Simulation, Disk and Corona, and LMXB Illustration — Black
  Hole Outburst. Each appears once only in the v4 timeline. Credits, links,
  hashes, and the usage rule are in `assets/universe_impact_fresh_v4/SOURCES.md`
  and the v4 manifest.
- No source audio, external soundtrack, or legacy video footage is used in the
  visual rebuild. The original locked program audio remains exactly as reviewed.

## Re-render v4

Dependencies are listed in `requirements-universe-impact.txt`. If system
FFmpeg is unavailable, the script can use `imageio-ffmpeg` through the local
Python environment.

```bash
python3 build_universe_impact_fresh_3d_v4.py --render-only --force
```

The command creates every unique original track, checks source uniqueness,
renders the 34-shot narrative plus outro, burns captions, stream-copies the
locked audio, extracts the cover, writes the SRT/source notes/publishing pack/
manifest, measures the unchanged audio, and performs decode/frame-fill QA.

`FFMPEG_BIN=/path/to/ffmpeg` optionally selects a specific FFmpeg executable.

### Required Edge-TTS configuration

The build script retains the requested settings and a `socket.getaddrinfo` /
`aiohttp` `ThreadedResolver` workaround for `speech.platform.bing.com`:

```text
engine: edge-tts
voice:  en-US-ChristopherNeural
rate:   +0%
```

On an Edge-permitted host, `--voice-only --force` creates fresh audit voice
files using that exact configuration. This does **not** change v4's locked
production audio; any audio remaster would require separate approval so the
reviewed loudness/treatment stays intact.

## Scientific editorial guardrail

“Black-hole cosmology” remains speculative. Keep “hypothesis,” “conceptual
model,” and “no direct proof yet” in captions or replies. Do not promote the
Reel as evidence that NASA, JWST, or any observatory has proved humanity lives
inside a black hole.
